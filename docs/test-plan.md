# 统一测试清单（2026-11-04，build 23764881）

一次测完所有已部署、还没验证的东西。整个流程大约 30–40 分钟，**只需要重启一次游戏**。
每一项都会写日志，你不用记细节，只需要记下"看到了什么、哪里不对"。测完告诉我，我运行 `tools/collect-test.ps1` 收集全部结果。

已启用的 mod：**VBTools**（单机工具）、**VBMP**（幽灵傀儡）、**VBTrace**（探针）。
热键一览：

| 热键 | 作用 |
|---|---|
| Ctrl+F1 … F5 | boss：查看 / 解除卡死 / 下一阶段 / 击杀 / 场地判胜 |
| Ctrl+F6 / F7 | 三合一合成 / 合成报告 |
| Ctrl+F8 | 背包面板开关 |
| Ctrl+F9 | 开始/停止录制破坏 |
| Ctrl+F11 | 回放录制的破坏 |
| Ctrl+Shift+H / J / L / G | 联机：开房 / 加入好友 / 离开 / 本机回环 |

## 回放实验（需要切一次存档）

| # | 操作 | 预期 |
|---|---|---|

| T13 | 同一个菜单里选 2，恢复 T7 记下的 `ingame-…` 槽 | 提示恢复成功 |
| T14 | 启动游戏，继续，走到 T8 的地点，按 **Ctrl+F11** | 之前打碎的东西按原来的顺序重新碎掉 |

T12–T15 不想做也可以跳过：在 T8 录完后，原地对着**还没打过**的物体按 Ctrl+F11 也能看出一些效果，但不如完整实验准。

## 联机测试（需要第二台电脑 + 第二个 Steam 账号）

前提：
- 另一台电脑装了 VOID/BREAKER（另一个 Steam 账号，和 gaming PC 上的账号**互为好友**）
- 把 `dist\VBMP-0.2.0.zip` 拷过去，解压后双击 `install.bat`（gaming PC 已经装好了，不用再装）
- 两台电脑都先在面板上点 [离开]，退出回环模式

| # | 操作 | 预期 |
|---|---|---|
| M1 | 两台电脑都启动游戏，进入大厅或同一个关卡 | 正常进入 |
| M2 | gaming PC：面板 [开房] | 联机区显示"模式：房主　状态：hosting" |
| M3 | 另一台：面板 [加入好友] | 几秒内显示"状态：connected"，并列出房主的名字和延迟 |
| M4 | 两边各自走动 | 都能看到对方的小白人，头顶是对方的 Steam 名字，移动顺滑 |
| M5 | 一方进入另一个关卡 | 对方那边的小白人消失；回到同一关卡后重新出现 |
| M6 | 客户端 [离开] / 直接退出游戏 | 房主那边的小白人在 10 秒内消失 |

如果 M3 一直连不上：记下两边联机区显示的内容。我会根据日志判断是好友发现、会话接受还是收发包的问题。
